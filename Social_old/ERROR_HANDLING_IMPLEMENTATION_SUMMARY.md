## 🛡️ **ERROR SCENARIOS COVERED**

### **Network Issues** ✅
- Offline detection: "You are now offline"
- Connection restored: "Connection restored. You are back online."
- Network errors: "Network connection issue. Please check your internet and try again."

### **Server Errors** ✅
- 500 errors: "Server error. Please try again later."
- 502/503/504: "Service temporarily unavailable. Please try again in a moment."
- Timeout errors: "Request timed out. Please try again."

### **Authentication Errors** ✅
- 401 errors: "Please log in again to continue."
- 403 errors: "You don't have permission to perform this action."
- Session expiration: Automatic redirect to login

### **Validation Errors** ✅
- Required fields: "Please fill in all required fields."
- Email format: "Please enter a valid email address."
- Password strength: "Password must be at least 8 characters long."

### **File Upload Errors** ✅
- File size: "File is too large. Please choose a smaller file."
- File type: "Invalid file type. Please choose a supported file format."
- Upload failures: "Failed to upload file. Please try again."
